# 다음 버전 제안

제작자 SunjooAn · 기준 버전0.10.0 · 2026-10-31. 아래는 제안이며 아직 구현하지 않았습니다.

| 우선순위 | 제안 | 사용자에게 달라지는 점 | 완료 판단 |
|---|---|---|---|
| 1 | 선택형 OBS 연결 | 공유 소스·하위 장면도 실제 프로그램 전환을 기준으로 재시작하고 앱에서 재등장/퇴장을 조작 | 같은 소스를 양쪽 장면에 사용한 Cut/Fade 전환도 처음부터 재생 |
| 2 | 반복 이음새 검사 | 반복 시작/끝을 나란히 보거나 겹쳐 보고 자연스럽게 이어지는지 확인 | 경계 비교와 짧은 연결 보정 미리보기, WebM/브라우저 동일 결과 |
| 3 | 원본 포함 프로젝트 저장 | PNG와 설정을 하나로 묶어 다른 PC에서도 바로 열기 | 상대 경로·누락 파일 다시 연결·가져오기 후 출력 재현 |
| 4 | 선택·마스크 정밀도 | 펜의 곡선 손잡이, 비파괴 경계 축소·색 번짐 보정, 고배율 비교 | 얇은 글자와 둥근 배지 경계 개선, 원본으로 되돌리기 |
| 5 | 키프레임 곡선 편집 | 속도 그래프와 손잡이로 바운스·이동의 가속도를 직접 조절 | 채널별 곡선/시간 조절과 기존 모션 호환 |
| 6 | 대형 원본 미리보기 최적화 | 프리뷰 해상도를 자동 조절하고 FPS·생략 프레임을 확인 | 원본 출력 품질 유지, 큰 그룹·마스크에서 편집 반응 개선 |
| 7 | 방송용 프리셋·에셋 정리 | 효과를 강도·색·시간과 함께 저장하고 검색·분류 | 프리셋을 다른 PNG에 적용하고 이름/썸네일로 관리 |

**v0.11은 OBS 연결과 반복 이음새 검사를 먼저 권장합니다.** 방송에서 재생 시점을 맞추고 반복이 끊기는 문제를 줄이는 효과가 가장 큽니다. 그다음 원본 포함 프로젝트 저장을 더하면 PC 이동과 자료 관리가 편해집니다.

가격 자동 탐지/OCR과 효과 사운드는 기존 사용자 결정에 따라 우선 범위에 넣지 않았습니다.
