# LiveCG-EFF v1.5.0 완료 보고
2026-11-07 · 제작자 SunjooAn

상단을 이미지 추가·작업 열기·저장·이미지 교체·저장 방송 갱신으로 정리하고 세부 설정과 이전 ZIP 방식은 메뉴 안으로 옮겼다.
작업에 출력 연결을 저장해 다른 위치로 옮겨도 원본과 출력 폴더를 찾는다. 이미지 교체 후 한 번의 저장 갱신으로 같은 index.html을 유지하며 OBS에 반영한다. 내부에는 현재와 직전 자료만 남긴다.
장면 내보내기 JSON을 새 경로로 연결한 사본을 만들고 실제 OBS에서 연결한 경로로 재생하는 것을 확인했다.
상세 검증과 패키지 무결성은 docs/verification/v1.5.0에 기록한다. 이전 버전 출력은 최초 갱신 후 OBS 새로고침 한 번이 필요하다.
