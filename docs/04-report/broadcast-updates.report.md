# LiveCG-EFF v1.4.0 완료 보고
2026-11-06 · 제작자 SunjooAn

두 PC 사이 수정 자료를 방송 ID로 연결한다. 작업용 PC는 방송 갱신 ZIP을 만들고, 방송용 PC는 같은 앱의 방송 자료 관리에서 가져오기·미리보기·반영·직전 버전 복구를 수행한다. ID별 고정 entry.html은 새 프레임의 자료 준비 후 반복 경계 또는 즉시 교체한다. 파일명과 전달 위치가 달라져도 같은 ID의 수정본으로 반영한다.

원본 파일 지문을 저장해 작업 폴더 내부의 폴더명·파일명 변경을 찾는다. 내용까지 바뀐 원본은 직접 연결·이미지 교체로 지정한다. 새 방송 자료 복제는 새 ID를 만들며 저장된 작업에서 계속 수정하면 같은 ID를 유지한다.

코어/편집기 회귀, 준비·반영·복구와 반영 실패의 기존 자료 보존, 경로·ZIP 무결성, 실제 Chromium/OBS의 소스 유지 갱신과 프로그램 재등장을 검증했다. 상세 수치는 검증 요약에 기록한다.

배포 ZIP의 최상단 LiveCG-EFF.exe를 실행한다. 처음 적용 시 방송 자료 관리의 OBS HTML 경로를 등록해야 한다. 방송 보관 폴더 자체를 이동하면 OBS 경로를 다시 연결한다. 관리창을 닫아도 로컬 HTML은 동작하며, 이전 방송 자료 버전은 보관한다.
