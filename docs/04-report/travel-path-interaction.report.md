# LiveCG-EFF v1.2.1 완료 보고
2026-11-02 · 제작자 **SunjooAn** · PDCA travel-path-interaction

여행 경로를 빈 지도에서 우클릭으로 작성하고, 선을 직접 끌어 여러 곡선점을 편집한다. 출발·경유·도착 역할을 구분·수정하며, 전체 이동+정차 시간을 지정하면 실제 궤적 길이별로 시간을 자동 배분한다. 시간이 부족하면 기존 값을 유지하고 안내한다.

수평·기울어진 수평 이동의 아이콘 지붕을 위로 유지한다. 새 경로 기본값은 예정선 끔·도착 강조 켬·전체 반복 켬이며, 이름과 편집 마커는 출력하지 않는다. 여행 효과는 직접 지정한 지도 안의 독립 오버레이로 적용하고, 다음 영역을 자동으로 그룹 안에 넣지 않는다. 에셋의 지도 비율 변경·기존 클립 잘라내기도 지원한다.

Core568 + WPF467 + Chromium145 + 프로그램 시계5 + 실제 OBS48 + 렌더 비교115 = **1,348/1,348 통과**. Debug 경고0/오류0. 집중 검사 Core52/WPF25는 위 검사에 포함되며 중복 합산하지 않는다. 실제 제공 가격 캡처 검출1개는 로컬 선택 검사이며 이미지 자체는 공개하지 않는다. 공개 증거는 합성 지도와 검사 결과다.

배포 파일은 **LiveCG-EFF-1.2.1-win-x64.zip**이다. 압축을 풀고 최상단 LiveCG-EFF.exe를 실행하며 app/사용안내/licenses를 함께 보관한다. 새 동작을 방송에 반영하려면 최신 앱에서 **OBS 브라우저 패키지를 다시 출력**한다. 기존 저장 경로·설정·원본·작업·에셋과 Git 개발 기록은 보존한다.

공개 main/태그와 ZIP의 크기·SHA256을 확인한 후 이전 v1.2.0 배포 및 테스트 생성물을 정리한다. 최종 배포 무결성은 별도 package-report.json/release-integrity.json에 기록하여 ZIP 내부 문서의 자기 해시 순환을 피한다. 다음 개발은 추가 사용자 요청에 따라 진행한다.
