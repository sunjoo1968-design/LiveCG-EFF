# LiveCG-EFF v1.0.0 완료 보고
2026-11-01 · 제작자 **SunjooAn** · PDCA v1-output-workflow

좌측 출력 설정에서 반복 횟수·사이 쉬기·표시 방식을 조절하고 구간 창과 공유한다. 총 출력 길이·프레임을 즉시 계산하며 선택파일 반복 설정 일괄 적용·기본값 저장·1회+쉬기 확인·출력 예정 목록·OBS 파일 위치를 제공한다. 타임라인의 출력순서띠가 등장·반복·쉬기·퇴장 흐름을 표시한다.

새 작업은 반복 사이 원본 유지1초이며 WebM은 마지막 쉬기를 생략하고 OBS는 무한 반복한다. 마지막 모습/전체 투명도 선택한다. 이전 프로젝트 누락 값은0으로 유지하고 구버전 사용자 기본값에는 새 작업용1초를 보완한다. 퇴장 요청은 효과 끝에 처리하며 쉬는 중에는 즉시 퇴장한다. 원본 쉬기는 레이어 캐시를 보존한다.

OBS는 원본명_index.html/원본명_preview.html 및 명시 manifest 경로를 출력한다. 내부 PNG는 실제 인코딩한다. PNG/JPG/JPEG/BMP/정적WebP와 JPEG EXIF 회전을 공통 경로로 처리하고 크기 변경·출력 동명 충돌을 감지한다. 새 영역은 배경 고정·내용만이 기본이다. 패널 폭/편집높이/분리창 크기를 잠그고 사용자의 최신 예외인 레이어 목록 높이 조절은 유지한다.

코어463 + WPF390 + Chromium93 + 시계5 + 실제 OBS33 통합26 + 렌더 비교63 = **1,040/1,040**. Debug 경고0/오류0. 실제 WebM55프레임/5.5초와 원본 쉬기, EXIF/이미지 입력, 설정 동기화·저장·Undo, 최소창 자료목록·레이어 높이를 확인한다. 브라우저와 실제 OBS 쉬기 화면도 원본 픽셀과 비교한다. OBS는 별도 portable 설정이며 송출·녹화하지 않는다.
