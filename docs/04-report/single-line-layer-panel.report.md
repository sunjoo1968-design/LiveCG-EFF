목록 아래 구분선은 높이를, 패널 왼쪽 구분선은 너비를 조절한다. 100개 영역의 내부 스크롤·가상화를 확인했고 실제 새 창에서 크기 복원을 검증했다. 저장 값은 유한값과 화면 범위로 제한한다. 이전 영역바 창/접기 설정은 무시하며 원본 편집·효과 속성의 창 분리는 유지한다.
