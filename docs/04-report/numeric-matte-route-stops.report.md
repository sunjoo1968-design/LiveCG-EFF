# LiveCG-EFF v1.2.2 완료 보고
2026-11-02 · 제작자 **SunjooAn** · PDCA numeric-matte-route-stops

정밀 분리 후 숫자 롤링이 원래 글자 모양에 잘리던 문제를 수정했다. 숫자·가격 우선 프리셋과 자동 보호색·옅은 가장자리 보호를 추가하고, 복수 배경에서 애매한 픽셀은 원본으로 보존한다. 획 축소·침식을 적용하지 않으며 수동 분리 보정과 타임라인 마스크를 유지한다.

정차 슬라이더 아래 초 입력/적용을 제공한다. 지점별 이동 조절은 제거하고 전체 시간 안에서 궤적 길이별 자동 배분으로 통합했다. 모든 출발·경유·도착 지점을 이름 없이 정차 시간에만 강조하고 이동하면 지운다. 0초 통과와 마지막 정차 종료 뒤에는 강조를 표시하지 않는다.

Core595 + WPF483 + Chromium168 + 프로그램 시계5 + 실제 OBS62 + 렌더 비교140 = **1,453/1,453 통과**. Debug 경고0/오류0. 이번 기능 집중 Core28/WPF16은 전체 검사에 포함되며 중복 합산하지 않는다. 첨부 이미지와 원본 자료는 공개하지 않았으며 합성 숫자·무늬 배경·지도 및 검사 결과를 공개 증거로 남겼다.

배포: **LiveCG-EFF-1.2.2-win-x64.zip**의 압축을 풀고 최상단 LiveCG-EFF.exe를 실행한다. app/사용안내/licenses를 함께 보관한다. 기존에 저장한 분리의 가장자리도 개선하려면 **정밀 분리·보정 → 숫자·가격 우선 · 획 보존 → 보정 적용**을 실행한다. 일반 오브젝트에는 기존 분리 방식을 유지한다. 배경과 같은 글자색·모호한 압축 잡음은 포함/제외 브러시로 보정할 수 있다.

OBS 방송에 반영하려면 최신 앱에서 **브라우저 패키지를 다시 출력**한다. 별도 런타임 설치가 필요하지 않다. 새 공개 배포의 커밋·태그·ZIP 크기/SHA256을 확인한 뒤 이전 v1.2.1 배포와 개발/검사 생성물을 정리한다. 사용자 원본·작업·에셋·실행 중 앱과 Git 개발 기록을 보존한다. 최종 ZIP 무결성 정보는 별도 package-report/release-integrity JSON에 기록한다.
