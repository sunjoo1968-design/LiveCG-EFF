# LiveCG-EFF v1.2.0 완료 보고
2026-11-02 · 제작자 **SunjooAn** · PDCA travel-routes-separation

흰 배경 숫자 롤링과 무늬 배경 분리·정밀 편집을 개선하고, 여행 경로 전용 편집창을 추가했다. OBS 출력과 방송 미리보기가 기본이며, 기존 프로젝트 출력 선택은 유지한다.

- 연결된 굵은 숫자 칸을 분할하고 마우스로 경계를 수정한다. 검출 실패 시 안내하며 최종 숫자는 원본 이미지로 정착한다.
- 여러 배경색·글자 보호색의 범위를 지정하고 실시간 미리보기로 조절한다. 획 축소 없이 원본 지지영역을 보존한다. 옵션·색·마스크 Undo/Redo, 별도 수동 patch 저장/재편집/크기 변경을 지원한다.
- 정지 프레임·분리 결과·선택 기록·소프트 조절선을 재사용하고 마스크 변환과 표시를 일괄 처리한다. 최종 출력 해상도는 유지한다.
- 여행 창에서 경유점·곡선·교통수단·방향·약한 애니메이션·궤적·지점별 정차/이동을 편집한다. 총길이를 계산해 지도와 독립된 타임라인 레이어에 넣고 내 에셋으로 저장한다. 도착 유지/전체 반복·그룹 마스크·숨김과 WebM/OBS 출력을 지원한다.

Core516 + WPF442 + Chromium126 + 프로그램 시계5 + 실제 OBS40 + 렌더 비교96 = **1,225/1,225 통과**. 빌드 경고0/오류0. 제공된 흰 배경 캡처의5자리 숫자 검출은 로컬 선택 검사로 확인했으며 해당 이미지 자체는 공개하지 않는다. 합성 자료로 획·수동 보정·정차·방향·도착·사용자 아이콘·알파 색·숨김·그룹 마스크를 확인한다.
