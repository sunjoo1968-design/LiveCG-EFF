# LiveCG-EFF v0.11.0 완료 보고

## 반영
효과 클립별 등장/반복/퇴장 배정, 자동 구간 추적, 다중 배정/우클릭/배지/정렬/경계 분할. 기본은 등장·반복, 퇴장은 선택형이며 끈 퇴장 효과는 출력에서 제외한다. 초·프레임 입력은 정밀 설정에 둔다. 기존 작업의 시간 방식과 퇴장 설정은 보존한다.

영역 소프트는 폭·강도·안쪽/바깥쪽/양쪽·4변별 폭을 지원한다. 원본 픽셀의 알파 경계를 처리하고 외부 여백을 포함한다. 청록/주황 범위선·손잡이 드래그·취소/Undo/Redo를 연결했다. 선택 표시 숨김은 보조선도 숨긴다. 소프트·배경 고정 바로 가기를 제공한다.

체크무늬/검정/흰색/검정·흰색 동시/사용자 이미지 비교는 편집용이며 출력에 넣지 않는다. 선택형 배경 고정은 단색의 경계 연결 배경을 분리하고 원본 글자 픽셀과 내부 동색 영역을 보존한다. 배경 스포이드·색상표와 허용오차를 사용한다. 그룹과 하위 영역, 숫자 효과 및 브라우저 자산에 반영했다. 반복 끝/첫 프레임 비교 창도 제공한다.

## 검증
**Core420 + 실제 WPF313 + Chromium73 + VM시계5 + 실제 OBS33 통합20 + 렌더 비교51 =882/882 통과**. Debug 0경고/0오류, Release publish 및 루트 실행/런타임/FFmpeg/아이콘/ZIP DLL해시 검사 통과.

5도형×3방향 소프트·중앙 불투명 보존·바깥 여백·4변 폭·원본 RGB/동색 글자 보호·저장/복사·클립 길이 추적·레거시·퇴장 제외를 검증했다. 실제 WebM은 등장+반복2회만 50프레임으로 출력하고 원본160×120을 유지했다. WPF에서는 폭 변경·범위 손잡이·기하 유지·취소/Undo/Redo·구간 배정/원본 비변경·비교 창을 확인했다.

독립 OBS portable 테스트로 사용자 설정과 분리하여 프로그램 전환과 소프트 외부/하위 그룹/배경 고정을 확인했다. 송출·녹화는 수행하지 않았다. 브라우저 비교 최대 평균오차 약1.92/255·채널차20초과 픽셀2.198% 이내이며 허용기준 내이다. 상세 [검증 요약](../verification/v0.11.0/summary.json), [렌더 비교](../verification/v0.11.0/render-comparison.json).

## 사용
1. 구간 설정에서 효과를 선택하고 등장/반복/퇴장에 배정한다. 필요하면 구간 순서 정렬 또는 경계 분할로 배치를 조정한다. 퇴장은 켰을 때만 출력한다.
2. 영역 선택 후 **소프트·배경 고정**을 눌러 폭/방향/강도를 조절하고 주황 손잡이로 직접 확인한다.
3. 단색 배경만 고정하려면 내용만 효과 적용을 켜고 배경색/허용오차를 조절한다.
4. 최신 앱에서 WebM 또는 OBS 패키지를 다시 출력한다. OBS에는 index.html을 넣고 기존 경로는 현재 페이지 캐시를 새로고침한다. 추가 런타임 다운로드는 필요 없다.

## 배포와 한계
실행: dist/LiveCG-EFF-0.11.0/LiveCG-EFF.exe. 전체 ZIP: dist/LiveCG-EFF-0.11.0-win-x64.zip. v0.10 원본 배포와 사용자 원본은 보존한다. 재개 예약은 삭제 상태를 유지한다.

소프트는 배경 자체를 제거하지 않는다. 배경 고정은 단색용이며 사진의 가려진 배경을 복원하지 않는다. 외부 소프트는 PNG 끝에서 제한되고 주변 원본이 포함될 수 있다. 구간 정렬은 마스크 시간을 자동으로 옮기지 않으므로 함께 확인한다. 공유 OBS 소스가 계속 활성 상태라면 기존과 같이 별도 소스/R/API가 필요하다. 새 설정 작업은 v0.11 이상에서 사용한다.
