# LiveCG-EFF v0.12.0 완료 보고
2026-10-31 · 제작자 **SunjooAn** · PDCA contextual-editor-ui

## 변경 결과
소프트/폭/방향/내용 처리/배경색/스포이드/정밀 분리·보정을 클립 속성에서 편집창 하단의 고정 바에 옮겼다. 고정·접기·별도 창과 복귀/배치 저장을 지원한다. 강도·4변·허용오차·배경 복구 방식은 세부 설정에 둔다.

우측은 문맥 경로와 접힌 영역 관리만 공통으로 표시하고, 클립 속성을 기본/시간·반복·구간/색상·모양으로 분류했다. 색을 사용하지 않는 효과는 관련 속성을 숨긴다. 기본 효과와 내 효과 검색도 분리했다.

그룹 구조/마스크 편집을 별도 내부 탭으로 나누었다. 그룹 연결 동작 이름을 명확히 하고, 마스크를 모양·적용/시간/움직임/가장자리/끝난 뒤로 분류했다. 선택 전에는 속성을 숨기며 타임라인 선택은 해당 화면으로 연결한다.

상단 오브젝트 맞춤은 정밀 분리·보정으로 통합했다. 자동 분리와 정밀 편집은 배경·허용오차·초기 마스크를 공유한다. 수동 마스크는 자동 색 분리를 다시 적용하지 않고 부분 alpha를 한 번 적용한다. 원본 자리 삭제 범위는 foreground 마스크와 별도로 보존하여 윤곽 잔상을 방지한다. 원래 선택 범위 유지가 기본이고 맞춤은 선택 옵션이다. 전체 영역 모드도 수동 마스크를 보관해 재활성/Undo가 가능하다.

## 검증
**Core431 + 실제 WPF342 + Chromium81 + 재생 시계5 + 실제 OBS33 통합24 + 렌더 비교59 =942/942 통과**. Debug0경고0오류, Release/배포 검사 수행.

정밀 초기 alpha·수동 보정 우선·비활성 저장·원본 RGB/단일 alpha·별도 source erase·모션 제작실 샘플을 검증했다. WPF에서 탭과 독립한 빠른 바, 관련 색상 표시, 원래 범위/브러시/Undo, 별도 창 편집/복귀와 중첩 분리창 복귀를 확인했다. 기존 프레임/마스크/효과/WebM 검사도 포함한다.

독립 OBS portable에서 프로그램 전환과 정밀 마스크/비활성 하위 영역까지 실제 CEF 스크린샷으로 비교했다. 사용자 설정과 분리했고 송출·녹화는 하지 않았다. 테스트 프로세스는 종료했다. [검증 요약](../verification/v0.12.0/summary.json)과 [렌더 비교](../verification/v0.12.0/render-comparison.json)를 보존한다.

## 배포
dist/LiveCG-EFF-0.12.0/LiveCG-EFF.exe 및 dist/LiveCG-EFF-0.12.0-win-x64.zip. 런타임·FFmpeg·외부 고지·안내 그림을 함께 포함한다. 사용자 원본과 v0.11 배포는 보존한다. 새 옵션을 반영하려면 패키지를 다시 출력한다. 재개 예약은 삭제 상태를 유지한다.

단색 분리의 적용 범위와 OBS 공유 소스의 지속 활성화 한계는 이전과 같다. 수동 보정 상태에서 색/허용오차 변경은 마스크를 임의로 재생성하지 않는다. 자동 분리로 되돌린 뒤 새로 계산하거나 정밀 창에서 명시적으로 다시 계산한다.
