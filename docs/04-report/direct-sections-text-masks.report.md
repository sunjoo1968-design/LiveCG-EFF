# LiveCG-EFF v1.1.0 완료 보고
2026-11-01 · 제작자 **SunjooAn** · PDCA direct-sections-text-masks

타임라인 구간 바를 마우스로 조절하고, 글자 안쪽 배경을 획 축소 없이 제거하며, 메인/정밀/효과/마스크 창의 메뉴를 정리했다.

- 경계 드래그는 자동 구간을 현재 경계 그대로 직접 조절로 전환한다. 반복 몸통은 길이를 유지해 이동하고 효과 클립은 이동하지 않는다. 스냅·ESC 취소·Undo·효과에 맞춤을 지원한다.
- 하단 영역바에 일반 오브젝트/글자·획 보존 대상을 추가했다. 글자는 정확한 배경을 제거하고 다른 원본 픽셀 지지영역·반투명도를 보존한다. 축소/페더 경로를 막고 원래 배경 재합성으로 확인한다.
- 정밀 분리·보정을 자동/브러시/결과 탭으로 나눴다. 글자 보호색, 배경 후보 찍기/확인/제거, 되돌리기, 재합성·차이 보기를 제공한다. 기존 수동 마스크는 명시 계산 전까지 유지한다.
- 편집/OBS 미리보기, 효과/영역/마스크 반복·색·시간·복제/삭제 용어를 정리했다. 중복 효과 목록·그룹 역할 편집을 제거했다. 고정 도구줄, 패널 잠금과 레이어 높이 조절, 삭제한 출력 배지 줄의 부재를 유지했다.

Core480 + WPF412 + Chromium96 + 프로그램 시계5 + 실제 OBS28 + 렌더 비교66 = **1,087/1,087 통과**. 빌드 경고0/오류0. 합성 글자의 닫힌 원/사각 내부 제거, 1px 획, 모든 경계 농도, 원본 알파, 재합성 오차<=1 검사를 포함한다. JPG 등 애매한 배경은 보수적으로 남길 수 있다.
