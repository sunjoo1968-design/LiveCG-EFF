설계12/12 충족. Core516 / WPF442 / Chromium126 / 프로그램 전환 시계5 / 실제 OBS40 / 렌더 비교96 = 1,225 검사. 빌드 경고0/오류0. 새 기능과 기존 동작 모두 회귀 검증한다. [요약](../verification/v1.2.0/summary.json)·[렌더 비교](../verification/v1.2.0/render-comparison.json).

동일 PC의 합성 1024×512 마스크 변환 검사에서 일괄 변환6.09ms, 이전 방식 참조450.60ms였다. 이는 해당 변환 작업의 측정이며 전체 앱 속도의 배수를 의미하지 않는다. 출력 원본 해상도는 유지한다.

실행 연동 검사에서 새 경로 레이어에 이전 영역의 배경/길이 UI값이 덮이는 문제를 찾아, 이전 선택을 먼저 확정하고 새 대상·클립을 구분하도록 수정했다. 곡선 끝점의 사용하지 않는0길이 손잡이와 마우스 캡처 취소도 점검했다. 수동 보정은 저장 후 재계산과 ROI 크기 변경까지 추가 검증했다.

한계: 유사한 배경/글자색과 사진 무늬는 보수적으로 남을 수 있다. 가려진 사진 배경 복원이나 기존 지도 선 제거·실제 도로 탐색은 범위 밖이다. 지도 경로 최대200지점/300초, 사용자 PNG 최대512px로 정규화. 사용자 자료는 로컬 선택 검사에만 사용하고 공개 캡처·fixture는 합성 자료만 사용한다.
