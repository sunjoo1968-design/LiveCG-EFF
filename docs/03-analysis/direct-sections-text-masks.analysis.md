설계 기능10/10 충족. Core480, WPF412, Chromium96, 프로그램 전환 시계5, 실제 OBS28, 렌더 비교66: 총1,087 검사. 빌드 경고0/오류0. 30fps 반 프레임(0.25초)을 비교하던 새 fixture는 실제 프레임인0.30초로 바로잡았다. 브라우저 시계의 프레임 양자화는 변경하지 않았다. 최종66/66 비교에서 모든 이미지가 기존 평균오차/차이픽셀 기준을 통과했다.

글자 모드는 단색 배경에 대한 보수적 분리다. JPG 잡음·그라데이션·글자와 배경의 동일한 색은 자동 복원할 수 있다고 보장하지 않는다. 모호한 원본 픽셀은 남기며 보호색·수동 브러시·차이 보기로 보정한다. 일반 오브젝트의 닫힌 내부 보존은 그대로 유지한다. 기존 수동 마스크를 글자 방식으로 갱신하려면 명시적으로 다시 계산해야 한다.

검증에는 공개 가능한 합성 도형·글자만 사용했다. 사용자 원본/사진·프로젝트·설정·인증 정보를 저장소나 배포본에 넣지 않는다. 배포 ZIP/실행·해시·공개 main/tag 일치 확인 뒤 이전 Release/태그·생성 캐시를 정리한다.
