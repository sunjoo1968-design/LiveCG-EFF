# 같은 폴더 저장·방송 갱신 검토
2026-11-07 · 제작자 SunjooAn · Match Rate 100%

작업별 출력 위치와 이전 절대경로를 저장한다. 작업 파일과 함께 옮긴 상대 위치를 우선하고, 폴더명이 바뀌면 manifest ID로 찾는다. 이전 버전의 출력도 영역 ID가 일치하는 data.js를 찾아 연결한다.
이미지 교체 후 저장·방송 갱신은 기존 index.html과 등록된 named index 별칭을 유지하며 작업과 전체 자료를 갱신한다. 정지 이미지도 포함한다. 편집 되돌리기가 이미 저장한 출력 연결을 끊지 않도록 처리했다.
내부 .livecg/revisions는 현재·직전만 보관하고 파일 이름이 바뀌어도 named entry를 추가로 늘리지 않는다. 새 자료가 준비된 후 pointer를 원자 교체하며 취소/다른 자료 ID 덮어쓰기를 거부한다.
원본·작업·출력을 묶는 이동용 저장도 출력 폴더를 포함한다. OBS 장면 JSON은 이전 출력경로를 새 index 경로로 연결한 사본으로 제공한다. 다른 미디어/카메라 경로는 수정하지 않는다.
실제 OBS에서 만든 장면 JSON의 경로를 변환한 뒤 옮겨진 폴더의 경로로 재생하고 파란 원본 픽셀을 확인했다. 실제 두 PC 대신 서로 다른 폴더/이름으로 경로 차이를 재현했으며 재생은 격리된 실제 OBS33으로 확인했다.
최초 새 출력부터는 자동 갱신된다. 이전 출력에서 이미 재생 중인 구형 HTML은 최초 한 번 갱신 출력 후 OBS 소스를 새로고침해야 한다. 이후 저장 갱신에는 재등록이 필요하지 않다.
