에셋 삽입 시 새 지도 비율로 시간을 재배분하며 사용자가 잘라 둔 클립 길이는 유지한다. 수동 모드의 실제 경유점 삽입은 정차1초가 추가되며 자동 모드는 전체 예산에서 다시 배분한다. 색/아이콘·경로 복사·JSON 저장·기존 그룹/마스크 검사도 통과했다.

초기 재현은 0/4 실패였으며 수정 후 4/4 통과했다. 최종 여행 집중 검사는 Core52/52, WPF25/25로 전체 검사에 포함된다. native/Chrome/실제 OBS의 곡선·수직/수평·ROI·그룹 마스크 비교115/115가 통과했다. 비교 허용치는 평균 채널 오차3 미만·오차20 초과 픽셀3.5% 미만이며, 완전한 픽셀 일치를 뜻하지 않는다.

설계 조정: 기존 그룹 관계가 자동 생성인지 사용자의 명시 연결인지 저장 데이터로 구분할 수 없다. 따라서 이미 연결된 그룹을 임의 해제하는 대신, 새 영역의 자동 부모 후보에서 여행 오버레이를 제외한다. 기존 그룹은 수동 연결/해제로 유지한다. 최소 이동 시간은1프레임 이상 및 기존0.016초 유효성 제한을 함께 만족시킨다.

원본 지도에 이미 그려진 선과 핀은 제거하지 않는다. 수평 계열은 실제 픽셀 접선의 |dx|≥|dy|로 구분한다. 정차 합이 전체 시간을 초과하면 조절값을 되돌리고 안내한다. 경로200지점·300초, 곡선점 구간32개/전체512개 제한이다.
