# v1.1.0 Design
2026-11-01 · SunjooAn

1. TimelineControl: 표면10px 손잡이, 자동모드도 드래그 허용. 실제 첫 이동에서 SectionRules.Resolve 경계를 저장하고 ByEffects=false로 변경. 반복몸통은 IntroEnd/LoopEnd를 같은 프레임 delta로 이동(길이 보존), 등장시작0 고정. 클립은 이동하지 않는다. ESC는 원래 PlaybackSections(자동 포함) 복원, 1회Undo. 중복 끝손잡이 제거·커서/시간 안내·자동/직접 표시와 효과에맞춤.
2. EffectRegion.SeparationTarget(Object 기본/Text), TextInkColor(빈값은 자동). 기존 문서 필드 누락은 일반 오브젝트. 텍스트 자동 분리와 정밀 창이 같은 TextSeparation 사용. 정확한 배경색 픽셀만 배경으로 제거하고 다른 모든 원본 지지픽셀은 alpha>=1 보존. 부분 원본 alpha는 그대로 사용한다. 주변 고대비 픽셀/보호색으로 단색 안티앨리어싱 혼합을 풀되 재합성 오차가 허용범위를 넘으면 원본 픽셀을 그대로 보존한다. 임계값 침식/1px축소/페더 없음. 손실압축 잡음은 보수적으로 남긴다.
3. RegionRaster.Raw에서 글자 Mask와 보정Foreground를 한 번 적용, 브라우저는 동일 PNG 자산 사용. 정밀 결과는 기존 Cutout Mask/Foreground/Erase에 저장. 수동 마스크는 자동으로 덮어쓰지 않는다. 텍스트 mode 선택 시 저장된 수동 보정 유지 안내·명시 재계산. 일반 오브젝트의 내부 보존은 유지한다.
4. 정밀창: 자동분리/브러시보정/결과확인 탭. 글자/일반 대상, 글자색 보호 스포이드/자동색, 배경색, 한 개의 계산/미리보기 적용. 글자 모드에서는 축소·페더·색번짐의 기존 침식경로 비활성. 안쪽배경 클릭은 정확한 배경색 연결성분 후보를 원본에 표시한 뒤 명시 제거, Undo. 원래 배경 재합성·차이 보기로 원본 비교. 수동 브러시 수정은 옵션 변화만으로 재계산하지 않는다.
5. UI: 미리보기 방식을 편집/OBS방송 선택으로 통합하고 반복 체크는 편집에만 노출. WebM 반복횟수/클립내반복/미리보기반복 구분. 영역배경색/효과색/비교배경 구분. 클립속성 중복 효과목록 제거(타임라인 주편집). 그룹연결은 명시3동작, 중복 역할편집은 정리. 확대/화면맞춤/키프레임FPS·시간·보간·복제/삭제 명칭을 창 전체에서 통일. 기존 데이터 모델·단축키 호환.
6. 새 Core/WPF 테스트는 자동→수동경계/몸통·스냅·최소프레임·취소/Undo, 글자 구멍/1px/AA/투명/다색/보호색/구멍후보·저장·Native/Browser/실제OBS와 원본재합성을 검증. 이전 Core463/WPF390/Chromium93/Clock5/OBS26/비교63 기준. 실제 사용자 사진은 공개하지 않고 합성 글자fixture만 사용.
7. v1.1.0 패키지/공개main·태그·ZIP hash 확인 후 v1.0.1 및캐시 정리. 최신패키지는 자가포함, SDK/FFmpeg 개발캐시는 재생성. 완료팝업/알림음1회. 작업중단체크포인트 저장.
