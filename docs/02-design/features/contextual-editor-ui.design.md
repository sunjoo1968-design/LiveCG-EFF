# v0.12.0 영역 조작·속성 UI — Design
제작자 SunjooAn · 2026-10-31

1. 편집창 밖 하단 AreaToolsHost/AreaToolsPanel에 선택영역 이름·소프트 on/off/폭/방향·내용 모드·공통 배경색/스포이드·정밀 분리 배치. 강도·4변·오차·배경 복구 모드는 상세에 둔다. 패널 접기/고정/별도 창·복귀, 작업 배치 저장. 클립 탭에 영역 설정을 두지 않는다.
2. 우측 공통헤더는 선택 경로만 표시하고 영역 관리·효과 추가/검색은 해당 문맥으로 이동. 클립 기본/시간·반복/색상·모양으로 분류, 색을 쓰지 않는 효과는 색상 패널 숨김. 전체 effects4탭은 유지한다.
3. 그룹·마스크 안을 그룹 구조/마스크 편집으로 나눈다. 관계 요약+그룹화/연결/분리, 역할 고급은 접기. 마스크 없으면 생성만, 있으면 모양·적용/시간/움직임/가장자리/끝동작을 표시. 타임라인 마스크 선택은 해당 탭으로 이동한다.
4. CutoutEnabled 선택 필드(기본true로 이전문서 호환). UI 내용 전체는 ContentOnly=false/CutoutEnabled=false, 내용만은 true/true. 저장된 수동 마스크는 유지하며 재활성 가능. Cutout이 활성화되면 자동 색 분리를 다시 적용하지 않는다. 공통 RegionSeparation helper로 빠른 분리·정밀 편집 초기 마스크/배경색/허용오차를 공유한다.
5. 정밀 창은 현재 마스크를 그대로 이어받는다. 자동분리 상태에서는 같은 마스크를 초기화하며 자동으로 색정리·축소를 하지 않는다. 브러시 보정/그림자/윤곽색 정리는 전문가 기능. 원본 선택 범위 유지가 기본이며 맞춤은 명시 체크 옵션. 적용은 마스크/배경/오차를 한 번에 기록하고 Undo/템플릿/출력으로 보존한다.
6. 의미 있는 Core/실제WPF 회귀·픽셀/자동→수동→저장→재열기/중복 분리 방지·최소/분리 UI 시각 확인. Chromium/실제OBS 출력·배포 검증. 버전0.12.0+SunjooAn. 이전배포/원본 보존, 재개예약 생성금지.
