## 현재 증상의 직접 근거

- v0.1 PreviewControl은 EffectRenderer.Render(...,600) 결과를 확대했다.
- v0.1 Zoom의 최대 확대량은 강도 최대에서도 8%, Bounce 이동은 영역 높이의 11% 이하였다.
- 모든 효과를 선택 사각형으로 클리핑했고 마지막에 원본 알파를 강제로 복구하여 바깥 확산/등장을 제한했다.
- 영역은 오른쪽 아래 핸들 하나만 있었고 숫자 좌표 UI를 병행하여 다중 선택 표시가 불명확했다.

화면 구조 회귀 기준(타임라인·좌표 삭제·3단계·줌·자동길이)을 먼저 v0.1에서 실패시킨 뒤 개편 검증으로 사용한다.
