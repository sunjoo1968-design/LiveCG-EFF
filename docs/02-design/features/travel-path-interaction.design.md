# v1.2.1 설계
2026-11-02 · SunjooAn

1. Follow 아이콘: 실제 픽셀 접선 각도에서 |dx|>=|dy|인 수평 계열의 좌향은 X반전+각도±180 보정으로 앞은 진행 방향, 지붕은 위. 수직 계열은 기존 회전. native/JS 같은 Pose 규칙. Horizontal/Fixed 명시 옵션은 유지.
2. 새 TravelRoute.Points 빈 배열. 내부 썸네일/검사/범용 Append는 명시 Example() 사용. 출력 Validate는 최소2점, 편집은0/1점 안전. 첫/중간/마지막은 출발/경유/도착 자동 역할, 명시 재지정은 순서 변경으로 유일성 유지. 편집 마커 색/모양/역할 표시. 방송은 이름/편집 마커 없음.
3. 우클릭 빈 곳은 끝에 추가, 점 위는 삭제/앞뒤 추가/출발·도착 지정, 선 위는 해당 구간 삽입 메뉴. 좌클릭은 점 이동과 곡선 편집만. 삭제로 빈 지도 복귀 가능, Undo/Esc·최소2점 적용 검사.
4. RoutePoint.CurvePoints는 들어오는 이동 구간의 비정차 굽힘점 배열(좌표와 in/out offset). 깊은 복사/유효성/캐시 포함. 곡선 켜기만으로는 직선 유지. 선 클릭 후 드래그는 de Casteljau 분할로 곡선점을 추가한 뒤 이동, 이후 다른 위치에 추가·이동·삭제 가능. waypoint와 다른 표시, 정차·역할·지점수에는 영향 없음. 64샘플/부분Bezier를 공통geometry로 출력하고 JS 고정64 인덱스 제거.
5. RouteGeometry metric(width,height)로 실제 픽셀 길이 측정. DurationBudget(nullable) 설정 시 정차를 프레임에 맞춘 뒤 남은 이동 프레임을 길이에 비례해 Hamilton 배분(각 구간 최소1프레임). 합은 정확한 총시간. 부족/범위 오류는 모델을 바꾸지 않고 안내. 점/곡선/정차 변경에 자동 재배분, 예산 해제 시 구간별 직접 시간. 에셋의 새 지도 비율에도 재배분.
6. FuturePath=false, Arrival=true, Repeat=true 새 기본값. Arrival은 원만, 이름 없음. 기존 저장된 명시 옵션/좌표는 보존.
7. 지도 ROI 없으면 직접 지정으로 유도하고 선택 후 전용창. 실제 선택 Bounds에서만 경로 생성, 새 OverlayOnly는 자동 그룹 후보 제외. 과거 OverlayOnly 그룹도 새 영역의 자동 부모로 선택하지 않는다. 이미 연결한 그룹은 자동/수동 여부를 안전하게 구별할 수 없으므로 기존 관계를 임의 해제하지 않고 수동 그룹 연결/해제로 유지한다. 적용 대상/이전 UI값 혼합 회귀 유지.
8. v1.2.1/제작자 표시, 경로·수평좌우·총시간·빈지도·역할·우클릭·곡선 드래그·ROI·그룹 Core/WPF검사 및 Native/Chrome/실제OBS 비교. 최신 패키지 공개 해시 확인 후 기존 배포 작업 흐름 정리. 원본과 Git 개발 기록 보존.
