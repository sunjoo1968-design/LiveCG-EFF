# v1.2.2 설계
2026-11-02 · SunjooAn · numeric-matte-route-stops

1. TravelRouteWindow의 정차 속성에 초 단위 정밀 입력과 슬라이더를 연결한다. 값 변경·잘못된 입력·자동 총시간 예산·Undo/Redo를 함께 검증한다. 지점별 이동 조절 UI는 없애고 전체 시간으로 조절한다. 기존 경로는 현재 총시간을 유지한 자동 배분으로 전환한다.
2. 기존 Arrival 옵션은 파일 호환성을 유지하며 모든 지점의 정차 강조로 바꾼다. RouteSample.Stopped와 해당 지점의 실제 Stop>0 및 정차 구간 안에서만 원을 출력한다. 출발/중간/도착 및 정차0·구간 끝의 동작을 native와 JS에서 동일하게 한다. 이름과 편집 표시를 출력하지 않는다.
3. 숫자 오류는 합성 무늬 배경+가격/할인율 텍스트의 실제 EffectScene 렌더링을 독립적인 투명 숫자 렌더와 배경 재합성한 참조와 비교해 재현한다. 분리·롤링·최종 합성 단계를 분리하여 원인을 확정한 후 수정한다. 수정 내용과 근거를 여기에 추가 기록한다.
4. 숫자 분리 기본 경로는 TextSeparation의 획 보존 정책을 따른다. 여러 배경색과 보호색을 구분하고 원본 비배경 픽셀·안티앨리어싱·작은 소수점과 쉼표·닫힌 내부 구멍을 보존한다. 침식/획 축소/임의 연결요소 삭제는 사용하지 않는다. 자동 분리와 수동 마스크/의도된 타임라인 마스크를 구별한다.
5. Core 재현 검사→UI 정확 입력/자동 이동/강조 옵션→브라우저/실제 OBS 픽셀 비교→패키지 검증. v1.2.2와 SunjooAn을 기존 표시 체계로 노출한다. 재현 자료는 합성본 위주로 공개하고 사용자 첨부/원본은 로컬 검사에만 사용한다.

## 재현 후 확정한 합성·획 보존 설계
- 같은 숫자 6,232개 참조 획 픽셀 중 저장된 Cutout 적용 시2,426개 누락. 숫자칸은4개로 동일, RangeMode를 꺼도 동일하며 Cutout 마스크만 제거하면0누락이었다. 입력 분리 마스크와 출력의 도형/소프트 경계를 분리한다.
- RegionRaster.Shape(includeCutout:false)와 Layer.NumericShapeImage 캐시로 숫자용 geometry를 제공한다. Core 숫자 렌더 후에는 이 geometry와 명시 MaskTrack만 적용한다. Browser에는 numericShape PNG를 내보내고 초기 로드 목록과 숫자 출력에서 함께 사용한다. 입력 foreground·수동 분리 보정·명시 타임라인 마스크는 보존한다.
- 색상 범위에서 보호색 미지정 시 배경 후보와 충분히 다른 최다 색 묶음으로 보호색을 자동 추정한다. 보호색-배경 혼합 경계는 범위 제거보다 먼저 처리하며, 여러 배경이 서로 다른 알파로 같은 픽셀을 설명하면 원래 픽셀을 남긴다. 원본 획을 축소하지 않으며 같은색/모호한 배경 잡음의 완벽한 제거는 보장하지 않는다.
- 숫자·가격 우선 버튼은 텍스트/범위/자동 보호색/배경24/보호36을 선택하며 기존 수동 patch를 유지한다. 정차 입력은0~30초, 프레임 단위로 맞추며 전체 시간보다 길면 되돌린다. 이동 조절과 자동/수동 전환을 없애고 기존 총시간을 유지한 길이별 자동 배분만 제공한다.
