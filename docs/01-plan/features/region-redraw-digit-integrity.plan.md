# v1.2.3 영역 재지정 숫자 무결성 계획
2026-11-02 · SunjooAn · PDCA region-redraw-digit-integrity

사용자가 제공한 가격1 이미지의 복합 붉은 배경에서133,470과21%를 검증한다. 첫 영역/글자 획 보존/숫자 롤링→영역 삭제→재지정의 실제 WPF 흐름과 정밀 분리→숫자 칸 편집 후 복구되는 차이를 재현한다. 이미지 자체는 공개하지 않는다.

캐시를 원인으로 단정하지 않는다. 같은 경계·미세하게 달라진 경계, 새 장면·기존 장면, 초기/재지정 모델과 숫자 칸·분리 알파를 비교할 수 있는 검사 루프를 먼저 만든다. 실패를 재현한 후 가설을 분리해 원인에 맞게 수정한다. 획 두께·쉼표/원 단위/할인율의 고정 부분과 기존 수동 보정을 보존한다.

완료: 사용자 자료에서 재현/원인 확인과 회귀 검사, Core/WPF/브라우저/OBS/배포 검증, 기존 배포 절차에 따른 공개·정리. 원본/작업/에셋·사용자 실행 앱·Git 기록 보존. 체크포인트를 저장해 중단 후 재개한다.
