# v0.11.0 효과 기준 구간·부드러운 경계 — Plan
2026-10-31 · 제작자 SunjooAn · 사용자 구현 승인.

목표: 초 입력 중심 구간을 효과 클립 배정으로 바꾸고, 선택형 퇴장·영역 소프트·배경 비교·선택형 배경 고정을 WebM/OBS 양쪽에 제공한다.

범위: 등장/반복/퇴장 클립 배정 및 경계 자동 추적, 다중 배정·경계 분할·초/프레임 정밀 설정. 새 작업은 구간 사용/퇴장 끔, 기존 작업은 호환. 소프트 폭/강도/안·밖·양쪽/변별 조절/범위선·드래그. 검정·흰색·체크무늬·사용자 배경 비교. 반복 양끝 비교. 단색 배경 고정·원본 픽셀 내용 애니메이션 선택. Undo/저장/복사/템플릿과 출력 동작 연결.

순서: 모델·네이티브 공통 래스터 → 재생 구간 → 편집 UI → OBS 자산·런타임 → 회귀/시각/출력 검증 → 0.11 별도 배포.

완료 조건: 기존 회귀 통과, 방향별 소프트 알파·외부 여백·배경 고정 픽셀 검사, 클립 길이 변경 추적·퇴장 없음 프레임 검사, 실제 WPF 조작/Undo, Chromium와 네이티브 비교, 패키지 기동/제작자·버전 확인.
