# v1.2.2 숫자 분리·롤링과 지점 정차 개선 계획
2026-11-02 · SunjooAn · PDCA numeric-matte-route-stops

1. 정차 슬라이더에 정확한 초 입력을 함께 제공한다. 이동 시간 조절 UI를 제거하고 전체 시간·경로 길이 자동 계산으로 통합한다.
2. 출발·경유·도착의 모든 지점을 정차 중에만 이름 없이 강조하는 옵션을 제공한다. 이동을 시작하면 강조를 지운다. 정차0초는 강조하지 않는다.
3. 색상 범위·무늬 배경 분리 후 숫자 롤링이 끊어지는 오류를 실제 렌더 경로에서 재현한 다음 원인을 분리한다. 숫자/가격/할인율을 우선하며 획 축소·침식으로 문제를 가리지 않는다.
4. 원본 글자 지지영역과 두께, 내부 구멍, 분리 결과 저장·재편집 및 마스크/그룹/소프트의 일관성을 확인한다. 같은 색의 배경과 글자는 보수적으로 보존하고 수동 보정을 유지한다.
5. 네이티브·브라우저·실제 OBS·WPF·패키지를 검증한 후 기존 배포 절차를 따른다. 원본/작업/에셋/사용자 실행 앱과 개발 이력은 보존한다. 작업 중단 시 WORK_IN_PROGRESS.md/RESUME.md에서 재개한다.

완료 기준: 정확 입력/자동 이동 UI·Undo/Redo, 정차 강조 구간, 무늬 배경 롤링 재현의 red→green, 원본 획 보존과 출력 간 비교, 최신 버전/제작자 표시, 검증된 Windows 배포본.
