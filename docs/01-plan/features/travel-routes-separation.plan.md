# v1.2.0 계획 · 여행 경로와 분리 안정화
2026-11-02 · SunjooAn · PDCA travel-routes-separation

사용자가 승인한 전체 제안: 흰/어두운 배경 숫자 롤링·붙은 숫자 경계 검출/수동 칸 조정, 정확 단색/색상 범위 분리 및 다중 배경/보호색, 획 보존, 정밀 분리 즉시 미리보기·설정/마스크 Undo/Redo·수동 보정 보존, 영역 선택/소프트/분리 캐시·비동기 미리보기 속도 개선. OBS 출력/방송 미리보기를 기본·메뉴 첫 항목으로 하고 WebM 전용 설정은 숨긴다. 기존 저장 작업의 출력 선택은 유지한다.

여행 경로 전용 편집창: 지도 위 클릭 경유점/이동·삽입·삭제·순서·이름·곡선 손잡이, 기본 교통 아이콘과 사용자 PNG/WebP, 이동 방향·약한 보조 애니메이션, 선/점/파선/화살표·색/굵기/투명/외곽, 지점별 정차 기본1초/일괄 적용·구간별 이동, 총길이 자동, 예정/지나온 경로·도착 표시·교통수단 변경·도착 유지/반복, 내 에셋 저장, 기존 타임라인·WebM·OBS 동일 출력/프로그램 진입 재시작.

순서: 재현 가능한 Core/WPF 실패 검사 확보→분리/숫자/속도 수정→OBS 초기값→공통 경로 모델/렌더러/브라우저→편집창·저장·타임라인 연결→Core/WPF/Chrome/실제OBS/픽셀·성능 검사→자가포함 배포→공개 main/tag/ZIP 해시 검증→이전 배포/임시만 정리. 원본 자료·프로젝트·에셋·Git 개발 기록은 보존. 제작자 SunjooAn·1.2.0 상시 표시. 완료 시 채팅+Windows 팝업/알림음. 사용량 중단 시 WORK_IN_PROGRESS/RESUME 체크포인트로 계속한다.

완료 기준: 회귀 및 새 기능 검사 모두 통과, 원본 획 지지영역 보존/복잡한 배경의 보수적 한계 공개, 정밀창 조절/Undo/Redo 실제 UI 검증, 선택만으로 분리 재계산 없음, 경로 정차/방향/아이콘·선이 WebM과 OBS에서 같은 시점에 일치, 기존 문서/옵션 enum 호환. 배포 검증 전 이전 v1.1.0 삭제 금지.
