# v1.5.0 같은 폴더 저장·방송 갱신 설계
2026-11-06 · 제작자 SunjooAn
작업별 출력 폴더를 기억하고 작업 파일 기준 상대경로 및 출력 manifest ID로 이전 PC의 자료를 재연결한다. 저장 시 이전 절대 출력경로도 기록해 OBS 장면 JSON의 브라우저 local_file을 새 경로로 연결한 사본을 생성한다.
표준 출력과 저장·방송 갱신은 같은 LinkedOutput 경로를 사용한다. index.html과 이미 등록된 named index 별칭을 유지한다. 내부 .livecg/revisions는 현재/직전만 보관하고 pointer.js를 원자 교체한다. 다른 자료 ID의 폴더를 덮어쓰지 않는다.
상단은 자료 추가/작업 열기/저장/이미지 교체/저장·방송 갱신과 작업/편집설정/이전방식 메뉴로 정리한다. ZIP/ID관리창은 이전방식 메뉴로 이동한다.
검증은 초기출력→저장→폴더 이동→자동연결→이미지 교체→한번갱신, OBSscene경로연결, 경로고정/반복출력2버전유지, Chrome 및 실제OBS 동작을 포함한다.
