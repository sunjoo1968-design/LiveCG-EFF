# v0.12.0 영역 조작·속성 UI 정리 — Plan
2026-10-31 · 제작자 SunjooAn · 사용자 구현 승인.

목표: 소프트·배경 고정을 클립 속성 밖에서 바로 조절하고, 클립/그룹/마스크를 대상별로 분리한다. 정밀 분리·보정은 자동 결과를 이어받고 중복 계산하지 않는다.

범위: 편집창 하단 고정 영역 바(접기/고정/별도 창), 소프트 기본/상세·내용 모드·공통 배경색/스포이드·정밀 보정. 상단 그리기/보기 도구 간소화. 우측 공통 헤더 축소·효과/클립/에셋별 동작, 클립 기본/시간반복/색상모양. 그룹구조/마스크 내부 탭, 마스크 모양/시간/움직임/가장자리/끝동작. 정밀 분리 초기 마스크·수동 보정 우선·원래 선택 범위 유지 및 선택적 맞춤. 되돌리기/저장/분리창/출력 호환.

검증: 기존 회귀, UI 최소 크기/분리/복귀/선택 동기화/빠른 조작/색상 옵션 가시성. 자동→수동 마스크 동일/재열기/중복 적용 방지/비활성 복구/원본 범위 보존. WebM/Chromium/실제OBS 결과 및 배포 기동. 원본과 v0.11 배포 보존, 재개 예약 생성하지 않음.
